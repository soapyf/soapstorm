## 1. System Overview
This document specifies the integration of a performance-optimized **Thermal Mirage Distortion** system into our global weather engine. The goal is to simulate shimmering heat waves (refraction) driven dynamically by atmospheric parameters, wind flow data, and camera transformations. 

To maximize performance, the system uses a **Screen-Space Post-Processing Fragment Shader (GLSL/OpenGL)** backed by simple, faked global variables calculation on the CPU side, completely bypassing the need to manage individual surface temperatures.

---

## 2. Core Operational Constraints
The implementation must adhere strictly to these rules of thermal distortion visibility:
*   **Temperature Contrast (Not Absolute Heat):** The effect occurs when surface temperatures exceed air temperatures (gradient). Visibility begins around a **10°C delta**.
*   **Wind Suppression:** Active wind patterns disrupt thermal gradients. Strong wind vectors on the wind flow map must actively damp or completely flatten the distortion intensity.
*   **Viewing Geometry:** The effect is amplified at low, shallow grazing viewing angles and significantly multiplied when the player utilizes camera zoom (narrow Field of View).
*   **Material Exclusions:** The effect must naturally fade out over short distances and never distort foreground objects

## 3. CPU Global State Management (Weather Engine Integration)

Once per frame, the global weather manager computes a normalized baseline parameter and updates the active OpenGL shader uniforms. This abstracts complex material heat retention into a single performant calculation.

```cpp
// Run once per frame within the main weather system tick loop
void UpdateMirageWeatherSystem(GLuint shaderProgramID, float currentFOV, float totalTime) 
{
    // 1. Fetch current weather state parameters
    float sunIntensity  = GetCurrentSunIntensity();   // Range: 0.0 (night/heavy storm) to 1.0 (noon clear)
    float rainIntensity = GetCurrentRainIntensity();  // Range: 0.0 (bone dry) to 1.0 (deluge)

    // 2. Compute "Solar Delta" cheat (Simulates surface cooking under direct sun rays)
    // Assumes an uninhibited sun cooks surfaces up to 25°C higher than ambient air.
    float virtualSurfaceGradient = sunIntensity * 25.0f;

    // 3. Apply sudden weather attenuation (Rain immediately cools and neutralizes surface gradients)
    virtualSurfaceGradient *= (1.0f - rainIntensity);

    // 4. Normalize gradient to a 0.0 to 1.0 scalar range (Using 20°C as peak max threshold)
    float globalMirageBaseline = glm::clamp(virtualSurfaceGradient / 20.0f, 0.0f, 1.0f);

    // 5. Upload calculated state uniforms to the OpenGL Context
    glUseProgram(shaderProgramID);
    glUniform1f(glGetUniformLocation(shaderProgramID, "u_GlobalMirageBaseline"), globalMirageBaseline);
    glUniform1f(glGetUniformLocation(shaderProgramID, "u_CameraFOV"), currentFOV);
    glUniform1f(glGetUniformLocation(shaderProgramID, "u_Time"), totalTime);
}
```

## 4. Post-Process Fragment Shader Implementation (GLSL)

This stage samples the final scene texture alongside the scene depth map and wind vector buffer. It uses scrolling UV offsets driven by the engine's wind direction to dynamically warp pixels.

```glsl
#version 330 core
out vec4 FragColor;

in vec2 TexCoords;

// Bindings for Input Render Targets / G-Buffer Components
uniform sampler2D u_SceneTexture;    // Final color buffer of the rendered scene
uniform sampler2D u_DepthTexture;    // Depth texture map
uniform sampler2D u_NoiseTexture;    // High-quality, seamless, tileable 2D Perlin or Simplex noise
uniform sampler2D u_WindFlowMap;     // Game engine's runtime 2D directional wind flow buffer

// Weather Engine & Camera Uniform Vectors
uniform float u_GlobalMirageBaseline; 
uniform float u_CameraFOV;
uniform float u_Time;

void main()
{
    // 1. Foreground Separation & Clipping
    // Read the scene depth to protect first-person meshes and immediate environments
    float depth = texture(u_DepthTexture, TexCoords).r;
    
    if (depth < 0.1) {
        FragColor = texture(u_SceneTexture, TexCoords);
        return;
    }

    // 2. Fetch and Normalize Wind Map Parameters
    // Sampling the wind direction/speed map and remapping the 0->1 data space to directional -1->1
    vec2 windVector = texture(u_WindFlowMap, TexCoords).rg * 2.0 - 1.0; 
    float windSpeed = length(windVector);
    float windSuppression = clamp(1.0 - windSpeed, 0.0, 1.0);

    // 3. Dynamic Optics Magnification (Zoom Scale Factor)
    // Mirages amplify linearly as the lens compresses layers of hot air. Standard baseline FOV is 60.0.
    float zoomScale = 60.0 / max(u_CameraFOV, 1.0);

    // 4. Convective Noise Animation & Wind Advection
    // Force the heat waves to travel smoothly along the vector path defined by the wind engine
    vec2 scrollSpeed = windVector * 0.05; 
    
    // Overlay two distinct scrolling scales to disrupt obvious tiling artifacts
    vec2 noiseUV1 = TexCoords * 4.0 + (scrollSpeed * u_Time);
    vec2 noiseUV2 = TexCoords * 8.0 - (scrollSpeed * u_Time * 1.5);
    
    vec2 noiseOffset1 = texture(u_NoiseTexture, noiseUV1).rg * 2.0 - 1.0;
    vec2 noiseOffset2 = texture(u_NoiseTexture, noiseUV2).rg * 2.0 - 1.0;
    
    // Composite multi-layered noise values
    vec2 combinedNoise = (noiseOffset1 * 0.6) + (noiseOffset2 * 0.4);

    // 5. Final Strength Computation
    // Combine weather states, wind disruption coefficients, optics scale, and exponential depth falloff
    float finalStrength = u_GlobalMirageBaseline * windSuppression * zoomScale * (depth * 0.03);

    // 6. Coordinate Refraction Warp & Boundaries Clamp
    // Apply final screen space pixel distortion offset. 0.015 acts as a hard safety scalar.
    vec2 distortedUV = TexCoords + (combinedNoise * finalStrength * 0.015);
    distortedUV = clamp(distortedUV, 0.0, 1.0); // Safeguard against cross-border sampling artifacts

    // Render output
    FragColor = texture(u_SceneTexture, distortedUV);
}
```
